# 资料核验与版本约定

核心课程归档核验日期：2026-10-26；补充论文与官网条款核验日期：2026-10-31。官网首页为 Spring 2026；官网提供的往届归档是 Spring 2025、Spring 2024。本书只声称覆盖这三年的公开核心课程，不推断不存在的更早开课年份。

- `manifest.json`：逐讲与逐作业来源、原始链接、固定 commit、SHA-256、下载时间、PDF 页数、获取状态。
- `papers.json`：补充论文的标题、链接与摘要阅读状态。开源版本不保存摘要全文；标记 `read_abstract` 的论文不代表逐页精读。
- `review-sources.json`：深度审校新增原始来源、哈希与失败访问记录；PyTorch 网页受限时使用官方版本源码核对接口语义。
- `coverage-sources.json`：2026-10-27 遗漏补查的 Unigram、FP8、SimPO、RLAIF 等原始来源。
- `assignment-coverage.json`：逐年作业小题标识到章节的知识路由，不代表所有作业实现均已完成。
- `advanced-sources.json`：第 22–27 章进阶扩展的原始论文、摘要阅读状态和重点全文核验记录；不附带论文全文或摘要副本，这些扩展不冒充历年课程中的未公开内容。
- `review-update-sources.json`：2026-10-29 外部审阅建议落实的原始来源、读取状态与哈希；全文只作临时核对，M2 模型链接固定版本，不存入公开目录。
- `research-sources.json`：按知识主题组织的原始论文/官方文档、读取范围和哈希，覆盖词表损失、MLA/扫描、LoRA、检索、验证、压缩与低精度。
- `frontier-sources.json`：第 29–34 章（2024–2025 社区进展）引用的论文与技术报告，记录发布日期、对应章节与核对范围（`fulltext_checked` 为摘要与正文相关段落，`abstract_read` 为仅摘要）。
- `chapter-review-sources.json`：逐章审校时补充的原始资料，记录下载时间、哈希、字节数与核对范围。
- `model-configs/`：第 29 章 14 个开源模型在固定 revision 下的 `config.json` 副本；`index.json` 记录 revision、获取日期与 Hugging Face safetensors 元数据报告的总参数，`examples/architectures.py` 的公式与它逐个精确比对。
- `cache/`：按需生成的下载、抽取与 PDF 页面缓存，不随仓库发布。第三方原件的版权属于原作者。本书文字、公式讲解、示意图和教学代码独立编写。

公开仓库保留来源清单、版本与哈希，不附带完整课程 PDF、第三方仓库镜像、全文抓取和逐页摘录。读取本指南或构建 HTML 不需要这些原始资料。需要重新核验时运行 `python scripts/verify_sources.py --download`；这会生成缓存，核对下载文件与清单哈希。活动课程网页不是固定快照，若上游已更新，哈希不匹配应视为资料变化，不能冒充当时的页面。

已读取三年核心讲义的 Python 文本和 PDF 抽取文本，重点核对章节对应部分以及作业要求。PDF 中仅以图片呈现的内容不能保证全部被文本抽取捕获；未声称观看全部视频或复述课堂口述。本书不拷贝原课件中的图片。

2025 年作业归档页面的链接指向活动仓库 `main`，其中的旧文件已被改名或迁移。本次通过官方仓库历史，选取 2026-01-01 之前的最后一次提交恢复，固定链接记录在 manifest。2026 年页面仍链接 2025 年安全对齐补充作业；其来源年份保留为 2025，不算新的 2026 内容。

嘉宾课资料边界：2024 年 Ce Zhang / Aakanksha Chowdhery、2025 年 Junyang Lin / Mike Lewis、2026 年 Daniel Selsam / Dan Fu。课程表没有提供这些课的独立讲义链接，本书不根据嘉宾研究方向猜测实际授课内容。2024 年评估课还明确提示嘉宾课无录像。本书覆盖可核验的 1–17 讲及五组作业的知识主线；这些嘉宾课的独有口述内容不在已核验范围内。

重新运行 `python scripts/fetch_sources.py` 默认抓取当前公开链接；若要复现本次资料，应该优先按 manifest 中 `download_url` 和 `sha256` 下载验证，而不是重新解析最新首页。随着上游更新，课件和链接可能改变。
