## 检索与纳入规则

2026-10-10 至 10-11 的首次检索执行了 32 组查询，核对 53 篇候选论文的元数据，其中 30 篇进入新章节，另将 BitNet 2B4T 报告补入已有路线。该批方法覆盖 2024–2026 年，不能都按教程增补年份称为新论文。后续补查与原始筛选状态分别保存，历史候选的处理决定以对应日期为准。

检索覆盖权重与二阶校准、缩放与旋转、码本与位宽、FP4、量化训练、MoE、KV、Attention 及推理系统。首次 arXiv API 不可用时使用网页检索与引用追踪；后续增加 arXiv API 查询。宽泛查询有返回数量上限，整体属于代表性路线检索，不能视为穷尽的系统综述。

1. 搜索用于发现候选；题名、提交日期和算法内容回到论文与作者材料核对。
2. 区分首次提交、所读版本与核查日期，同名方法用论文编号区分。两篇 PolarQuant、两篇 OSCAR/OScaR 分别保留独立入口。
3. 纳入教程需要明确机制、可定位的正文与适用边界；只读摘要或元数据的候选，不据标题补写实现。
4. 论文报告的模型结果、作者实现、教学算例和本项目实测分别标注。网站可访问或代码存在不等于完整复现。
5. 公开记录保留查询、候选链接、版本、读取范围与 SHA-256；原始搜索返回正文只保留摘要哈希，不重复收录在仓库中。
